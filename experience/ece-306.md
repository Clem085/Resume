## Student Project — MSP430FR2355 Embedded Vehicle, Fall 2024

### System implementation

- Built and programmed an embedded vehicle around a TI MSP430FR2355 microcontroller and custom PCBs.
- Integrated IoT/Wi-Fi control, ADC-based line sensing, timer-generated motor PWM, LCD status output, GPIO, interrupts, timers, sensors, and serial communication.
- Implemented line-following behavior from ADC measurements and updated the LCD with system information in real time.
- Added two programmable buttons and a rotary dial/selector for choosing inputs and operating modes.
- Implemented software debouncing for button/switch inputs so physical contact behavior did not create unintended state changes.
- Used motor-control PWM only as required for the vehicle; this academic implementation is distinct from the professional programmable bidirectional power-conversion architecture.

### Hardware/firmware integration

- Mapped schematic and PCB connections to microcontroller pins and peripheral configuration.
- Brought up peripherals individually before combining sensing, control, display, and motion behavior.
- Debugged firmware state, timing, wiring, solder joints, sensor behavior, and custom-board interfaces.
- Used Code Composer Studio, serial diagnostics, debugger/register state, datasheets, and electrical measurements during integration.
