# ECE 306 Experience

## Embedded-System Vehicle Project

- Built and programmed an embedded vehicle using a TI MSP430 microcontroller and custom PCBs.
- Integrated IoT Wi-Fi control.
- Implemented ADC-based line-following behavior.
- Used PWM for motor control.
- Programmed an LCD to display system information in real time.
- Worked with timers, interrupts, GPIO, firmware state, serial communication, sensors, and board-level debugging.

## Teaching and Laboratory Support

- Supported students working through semester-long MSP430 embedded projects.
- Explained C, ADC, PWM, timers, interrupts, GPIO, LCD integration, serial diagnostics, and hardware bring-up.
- Diagnosed code, wiring, soldering, debugger, and custom-PCB failures across different student designs.
- Taught systematic debugging using datasheets, serial output, measurements, register state, and controlled tests.
- Delivered supplemental lectures and test preparation.
- Advised students on project design, course strategy, and ECE pathways.

## Distinction Between Project and Teaching Work

The vehicle project documents hands-on technical experience as an ECE 306 student. The teaching-assistant work documents later technical leadership, rapid diagnosis across many implementations, and the ability to teach embedded concepts to students with different experience levels.
